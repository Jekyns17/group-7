# Group 7 - Makerere University Student Website

A multi-page group website built by students of Makerere University. Each student designed and developed their own individual webpage reflecting their unique interests, hobbies, and visual aesthetics, united into one cohesive web platform through shared navigation.

## Project Architecture

- **Independent Stylesheets**: Each student has their own dedicated CSS file in `css/` (`bakhita.css`, `daniella.css`, `ernest.css`, `ntwari.css`, `ibrahim.css`, `matthew.css`).
- **Interactive Features**: Simple, modular vanilla JavaScript in `js/main.js` powering persistent like counters and message guestbooks via browser `localStorage`.
- **Responsive Layout**: Works seamlessly across mobile, tablet, and desktop screens.

## How to View

Open [`index.html`](index.html) or any of the student HTML files directly in any modern web browser.
